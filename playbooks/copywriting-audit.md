# Copywriting Audit Playbook

## Purpose
Use a strong reviewer to improve persuasion without inventing claims or degrading policy compliance.

## Audit dimensions
- clarity of the core promise;
- problem/desire intensity;
- specificity and credibility;
- differentiation;
- objection handling;
- proof quality;
- message hierarchy;
- friction and ambiguity;
- CTA quality;
- consistency across hero, PDP, FAQ, policies and checkout;
- claim safety / GMC sensitivity.

## Preferred workflow

```text
Local draft -> local critique -> frontier audit -> local application of changes -> final spot check
```

The frontier reviewer should return prioritized issues and rationale rather than rewriting every line by default. This keeps expensive reasoning focused on diagnosis.
