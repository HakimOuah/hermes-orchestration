# Learned Rules

This file records evidence-backed lessons from actual product research and launches.

## Status taxonomy

- **Observation** — plausible lesson, weak evidence.
- **Candidate rule** — repeated enough to monitor deliberately.
- **Validated rule** — strong enough to modify the playbook/scoring.
- **Retired rule** — previously accepted but contradicted by later evidence.
